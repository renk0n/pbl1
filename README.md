# エコタウン・クイズ（PBL1 4班）

小学校高学年〜中学生が、ひとりで、または保護者と一緒に遊べる気候変動のクイズゲーム。
クイズに答えると「なぜそうなのか」の解説が出て、環境ポイントで街が育つ。最後に「今日からやること」を1つ決め、次に遊ぶときに「できた？」と聞く。

流れ：事前テスト（6問）→ クイズ（ひとりで10問／親子で交代しながら12問）→ ふり返りと「今日からやること」えらび → 事後テスト（6問）→ アンケート

## 動かし方

```
npm install
npm run dev        # ブラウザで http://localhost:5173 を開く
npm test           # 自動テスト（ファイルを保存するたびに再実行。終了は q）
npx vitest run     # 自動テストを1回だけ実行
npm run build      # 本番用ビルド（dist/ にできる）
```

## インターネットで遊べるようにする（GitHub Pages）

体験会で、スマホやタブレットからURLを開くだけで遊べるようにする。

1. GitHub の pbl1 リポジトリを開き、Settings → Pages → Build and deployment の Source を「GitHub Actions」にする（最初の1回だけ）
2. main に変更が入ると、`.github/workflows/deploy.yml` が自動で「テスト → ビルド → 公開」をする
3. Actions タブで緑のチェックが付いたら、`https://renk0n.github.io/pbl1/` で遊べる

テストが1つでも失敗すると公開されない。古い版のまま体験会をしないよう、main に入れたあとは Actions タブを確認する。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/data/questions.ts` | 問題データ42問（quiz_table.xlsx の36問＋適応・備え6問）。分類・難易度・解説・出典つき。事前・事後テストの6問もここで決める |
| `src/data/actions.ts` | 「今日からやること」の候補と、親子モードの「話してみよう」 |
| `src/quiz.ts` | 出題（ひとり：★1〜3で10問／親子：こどもはテストの6問、おとなは★3〜5の6問を交代で）と採点（正解で難易度×10pt） |
| `src/game.ts` | 街の成長（30・80・150・250ptで5段階） |
| `src/habit.ts` | 「今日からやること」を続けるしくみ（できたら次回+20ptから始まる。決めた日と同じ日は聞かない） |
| `src/review.ts` | 分類ごとの集計、事前・事後テストの比較、アンケートのCSV |
| `src/storage.ts` | アンケート結果と「今日からやること」をブラウザ（localStorage）に保存 |
| `src/components/` | 各画面（テスト、クイズ、街、ふり返り、結果とアンケート） |
| `src/*.test.ts` | 自動テスト |
| `.github/workflows/deploy.yml` | GitHub Pages への自動公開 |

## 問題を追加・修正するには

`src/data/questions.ts` の `QUESTIONS` に1問ずつ追加する。`answer` は正解の選択肢の位置（0始まり）。
追加したら `npx vitest run` で、正解の番号や出典の書き忘れがないかを確認できる。

## 体験会での使い方

1. 同じ端末で何人か遊んでもらう。親子で遊んだときは、結果画面で「続けてもう1人回答する」から保護者も回答できる
2. アンケートには名前を書かない（回答者は「小学生／中学生／高校生以上／保護者」だけ選ぶ）
3. 最後にタイトル画面の「体験会の記録を見る」から、結果をCSVでコピーしてスプレッドシートに貼る

CSVの列：日時、回答者、モード、事前・事後テストの正答数と伸び、獲得ポイント、楽しさ・家でやってみたい・家族と話したい（各1〜5）、前回の行動（できた／まだ）、今日からやること、わかりにくかった言葉や問題、つまらなかったところ・あったらいい機能
